# 街坊库 · 邻里工具共享平台

> 电钻一年用两次，不必家家都买。「街坊库」让一栋楼的邻居把闲置工具共享起来。

本仓库先落地两块地基：**工具档案** 与 **邻居管理**。零第三方依赖，Node.js 原生 HTTP 服务 + 静态前端，`docker compose` 一键运行。

## 一键启动

```bash
docker compose up -d --build
```

打开浏览器访问 **http://localhost:8107**

停止 / 重置：

```bash
docker compose down          # 停止（数据保留在卷 jiefangku-data 中）
docker compose down -v       # 停止并清空数据，下次启动重新播种
```

> 不使用 Docker 也可以直接运行（需要 Node.js 18+）：
> ```bash
> node server.js
> ```

## 功能与权限

### 工具档案
每件工具记录：**名称、品类、押金、可借时段、安全等级、状态、物主**。

- **状态**：可借 / 已预约 / 借出 / 维修中 / 已下架
- **安全等级**：普通工具（可直接借）／ 需说明工具（档案中必须附安全须知，卡片上高亮展示，借用前须阅读确认）
- **押金规则（界面公示）**：**按件定额、按次收取**——每件工具有固定押金，每发起一次借用冻结一次押金；归还验收无损后全额退还，人为损坏按维修/折旧扣除。
- 楼长可新增 / 编辑全部工具档案，并**替邻居上架、下架**；普通邻居只读浏览。

### 邻居管理
- 登记每户的**楼栋、门牌、手机号**等联系方式。
- **列表对所有人一律脱敏**：只显示「楼栋 + 手机尾号」（如 `****0101`），楼长也不例外。
- **完整联系方式（门牌 + 完整手机号）仅楼长**可在住户详情页查看（用于借还联络与纠纷处理）；住户本人可查看自己的完整档案。
- 普通邻居尝试查看他人完整联系方式时，得到的是**明确的 403 错误态**（错误码 `CONTACT_PROTECTED`、原因说明与解决建议），而不是空白页。

## 初始数据

- **16 个账号**：1 位楼长 + 15 户邻居（1～3 栋）
- **24 件工具**：覆盖电动工具、手动工具、梯具、测量工具、清洁设备、园艺工具、五金搬运等品类；五种状态均有样本；冲击钻、角磨机、电锤、人字梯、高压清洗机、绿篱机等为「需说明」工具并附安全须知。

数据保存在容器卷 `/app/data/db.json`（本地直跑则在 `./data/db.json`），删除该文件可恢复初始数据。

## 技术说明

- 后端：Node.js 内置 `http`，会话用 HttpOnly Cookie + 内存会话表（重启需重新登录），所有越权访问在服务端鉴权并返回结构化 JSON 错误。
- 前端：原生 HTML/CSS/JS 单页，无构建步骤。
- 目录结构：

```
server.js              # HTTP 服务 + API + 权限校验
seed/seed.js           # 初始账号与工具数据
public/                # 前端（index.html / styles.css / app.js）
Dockerfile             # node:22-alpine，无 npm 依赖
docker-compose.yml     # 8107 端口 + 数据卷
```
