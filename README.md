# 街坊库 · 邻里工具共享平台（地基版）

电钻一年用两次，何必家家都买。「街坊库」是小区里的工具共享档案，本地基版包含两块核心：

- **工具档案**：名称、品类、押金、可借时段、安全等级（部分工具需阅读说明 / 楼长现场确认才能借）、状态（可借 / 已预约 / 借出 / 维修中 / 已下架）。
- **邻居管理**：每户登记楼栋门牌与联系方式，联系方式脱敏展示。

## 一键运行

```bash
docker compose up --build
```

访问 <http://localhost:8107>。数据存于 `jiefangku-data` 卷，重启不丢；首次启动自动建表并写入种子数据（25 件工具、16 户账号）。

## 平台规则（界面上也有展示）

- **押金按件收取**：每借一件工具缴纳该工具对应押金，归还验收后当场退还；多借多押，按件累计。
- **联系方式可见性**：完整手机号与门牌号**仅楼长（管理员）与本人可见**；普通邻居在列表与详情页只能看到**楼栋 + 手机号尾号**。越权访问完整联系方式会返回明确的 403 错误页，而非空白页。

## 技术栈与结构

Python 3.12 + Flask + SQLite（标准库，无外部服务依赖），单容器运行。

```
app/
├── app.py            # 路由、权限装饰器、脱敏逻辑
├── db.py             # 建表 + 种子数据（25 工具 / 16 户）
├── requirements.txt
├── templates/        # 登录、工具、邻居、403 错误页等
└── static/style.css
```

安全说明：密码经 werkzeug 哈希存储；`SECRET_KEY` 可用环境变量覆盖（`SECRET_KEY=xxx docker compose up`）。借用 / 预约流程、通知等属于后续楼层，本地基版不含。
